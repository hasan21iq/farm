# 🚜 مزرعتي — لعبة مزرعة الحيوانات

لعبة مزرعة حيوانات ثنائية الأبعاد للهواتف، تعمل **بدون إنترنت بالكامل** (PWA) وتحفظ تقدّمك على الجهاز.

## ✨ المميزات

- **5 أنواع حيوانات**: أبقار وأغنام من البداية، ثم دجاج (مستوى 2)، ماعز (مستوى 3)، جاموس (مستوى 5).
- **3 أعمار لكل حيوان** (صغير / متوسط / كبير) بأسعار شراء وبيع وعلف وسرعة نمو مختلفة.
- **الزراعة**: عشب، شعير، ذرة، برسيم — ازرع، انتظر، احصد، وخزّن. المحصول يذبل إذا تُرك.
- **الجوع والصحة**: الجوع يوقف النمو ويضر الصحة، والنظافة والازدحام يزيدان الأمراض.
- **الأمراض والطبيب**: 6 أمراض بثلاث درجات، استدعاء الطبيب للتشخيص ثم العلاج. المرض بدون علاج يسوء حتى النفوق.
- **البيع**: مشترون في ساحة البيع بطلبات ووقت انتظار، وسفينة تصل دورياً بطلبات كبيرة ومكافأة، وتاجر للبيع السريع.
- **التطوير**: الحظيرة، الحقول، المخزن، ساحة البيع، العيادة، المعلف الآلي، الميناء.
- **الوقت**: ليل ونهار (يوم اللعبة = 4 دقائق)، وأحداث عشوائية (موجة أمراض، جفاف، مطر، موسم العيد، غلاء...).
- **الحفظ التلقائي**: وعند إعادة فتح اللعبة يُحسب ما حدث أثناء غيابك (حتى يومين، بدون أمراض أو نفوق).

## ▶️ التشغيل

اللعبة ملفات HTML/JS فقط بدون أي مكتبات أو بناء.

**على الكمبيوتر:** افتح `index.html` مباشرة في المتصفح، أو شغّل خادماً محلياً:

```bash
python -m http.server 8000
# ثم افتح http://localhost:8000
```

**على الهاتف (تثبيت كتطبيق يعمل بدون إنترنت):**
1. ارفع المشروع على GitHub Pages (Settings ← Pages ← Branch: main).
2. افتح الرابط على الهاتف مرة واحدة وأنت متصل.
3. من قائمة المتصفح اختر **"إضافة إلى الشاشة الرئيسية"**.
4. بعدها تعمل اللعبة بدون إنترنت.

## 🛠️ التعديل

| الملف | المحتوى |
|---|---|
| `js/config.js` | **كل أرقام التوازن**: الحيوانات، المحاصيل، الأمراض، التطويرات، الأحداث |
| `js/game.js` | منطق اللعبة والمحاكاة والحفظ وأفعال اللاعب |
| `js/render.js` | رسم المزرعة والحيوانات والكاميرا واللمس |
| `js/ui.js` | الواجهة والنوافذ والإشعارات والأصوات |
| `js/main.js` | التشغيل والحلقة الرئيسية |
| `sw.js` | التخزين للعمل بدون إنترنت |

**لإضافة حيوان جديد** أضف عنصراً في `ANIMALS` داخل `js/config.js` (الأسعار، العلف، النمو، الشكل) وسيظهر تلقائياً في السوق والطلبات.

عند تعديل الملفات بعد النشر، غيّر اسم `CACHE` في `sw.js` (مثلاً `animal-farm-v2`) حتى تصل التحديثات للأجهزة.
